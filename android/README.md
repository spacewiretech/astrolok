# android

## Purpose

The Android build: Gradle config, the manifest, signing, and the per-environment Facebook
values. Application id `com.spacewire.astrolok`.

## Files

- `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties` — project-level Gradle.
- `app/build.gradle.kts` — the app module: `applicationId`, signing config, build types.
- `app/proguard-rules.pro` — release shrinker rules.
- `app/src/main/AndroidManifest.xml` — permissions and intent queries. `INTERNET`, `CAMERA`,
  `AD_ID`, and **`RECORD_AUDIO` explicitly removed** with `tools:node="remove"` (a dependency
  requests it; the app never records). `<queries>` declares the UPI apps the checkout can hand
  off to.
- `app/src/debug/` and `app/src/profile/AndroidManifest.xml` — the debug/profile overlays.
- `app/src/main/kotlin/com/spacewire/astrolok/MainActivity.kt` — the Flutter activity. No custom
  platform channels.
- `facebook.properties.example` — **committed template**; copy to `facebook.properties`
  (gitignored) and fill in `FACEBOOK_APP_ID` and the client token.
- `.gitignore` — also ignores `key.properties`, `*.keystore`/`*.jks` and `facebook.properties`.

## Notes

- **Neither Facebook value is a secret** — both ship inside every installed app. They are kept
  out of git because they are per-environment. The Facebook *app secret* belongs nowhere in this
  repo.
- With `facebook.properties` absent or blank the SDK is never initialised and the app behaves
  exactly as it did before the integration. One expected symptom, documented in the template so
  it is not mistaken for a bug: logcat shows a single
  `GeneratedPluginRegistrant: Error registering plugin facebook_app_events` at launch. The
  alternative — initialising with a blank app id — was measured and is worse: the SDK hammers
  the Graph API with OAuth 400s on every launch.
- Signing comes from `key.properties` + a keystore, both gitignored. A release build without
  them falls back to debug signing.
- App icons are generated by `flutter_launcher_icons` from `assets/images/app_icon.png`
  (currently an 80×80 source — see [../assets/README.md](../assets/README.md)).
- **`android/build/reports/problems/problems-report.html` is checked into git.** That is build
  output and almost certainly should not be tracked; left alone here rather than removed.
- Everything under `app/src/main/res/` (mipmap and drawable buckets) is generated. Not indexed.
